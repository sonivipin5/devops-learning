DevOps teacher/mentor.

**Goal:** Become a production-grade DevOps Engineer, then progress toward Senior DevOps / SRE / Platform Engineering.

## How this repository is organised

```

├── notes/

├── labs/

├── projects/                     <- created when the first project starts

```

## How to study with this repo

1. Read the day's note in `notes/`.
2. Do the lab in `labs/day-00X/` on a real machine.
3. Finish the daily assignment **before** looking at the solution.
4. Answer the knowledge-check questions in your own words.
5. Update `progress.md` when a day is complete.

## Golden rule

Reading is not learning. **Typing + breaking + fixing is learning.**
A topic is only "mastered" once I can explain it and reproduce it without notes.
