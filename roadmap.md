# DevOps Learning Roadmap

> Timeline is a **plan, not a promise**. Understanding beats speed.

| Period | Focus |
|---|---|
| Months 0–2 | Linux, Git, networking, scripting |
| Months 2–4 | Cloud (AWS), Docker, CI/CD |
| Months 4–7 | Terraform, Kubernetes, monitoring |
| Months 7–12 | Security, scaling, reliability, production-style projects |
| Month 12+ | Advanced DevOps, platform engineering, architecture |

---

## Level 1 — Foundations (Months 0–2)

**Computer and Operating System Fundamentals**
- What is an operating system?
- Windows versus Linux
- Files, directories, processes, and memory
- CPU, RAM, disk, and networking fundamentals
- Client-server architecture
- Virtual machines and virtualization

**Linux**
- Linux architecture and distributions
- Ubuntu installation and setup
- Terminal and shell, basic commands
- File and directory management
- Permissions and ownership
- Users and groups
- Processes and signals
- Services and systemd
- Package management with APT
- Environment variables
- SSH
- Logs and troubleshooting
- Disk and memory usage
- Cron jobs
- Basic Linux security

**Git and GitHub**
- Version control concepts
- Git installation and configuration
- Repositories
- Working directory, staging area, commits
- Branching and merging
- Pull requests
- Merge conflicts
- `.gitignore`
- Tags
- GitHub workflows
- Collaboration practices

**Networking**
- What is a computer network?
- LAN, WAN, public IP, private IP
- IPv4 and subnet basics
- TCP and UDP
- DNS, DHCP
- MAC addresses
- Ports and sockets
- HTTP and HTTPS
- TLS fundamentals
- Firewalls, routing, NAT
- Proxies and reverse proxies
- Common networking commands

**Scripting and Configuration**
- Bash fundamentals
- Variables and data types
- Conditions and loops
- Functions
- Command-line arguments
- Exit codes
- Pipes and redirection
- Python fundamentals for automation
- YAML, JSON
- Script troubleshooting and debugging

---

## Level 2 — Junior DevOps (Months 2–4)

Cloud computing fundamentals · AWS core services (IAM, EC2, S3, VPC, Route 53, RDS,
CloudWatch) · Linux servers in the cloud · Docker fundamentals · Images, volumes,
networks · Docker Compose · Container registries · CI/CD concepts · GitHub Actions ·
Build/test/scan/deploy pipelines · Artifacts and versioning · Basic deployment
strategies · Cloud cost basics.

## Level 3 — Intermediate DevOps (Months 4–7)

Terraform (providers, state, modules, workspaces, remote backends, drift) · Ansible
(inventory, playbooks, roles, idempotency, vaults) · Kubernetes (architecture, pods,
deployments, services, ingress, configmaps, secrets, volumes, resource limits,
namespaces, RBAC, autoscaling, troubleshooting) · Helm (charts, values, templating) ·
Monitoring and logging (Prometheus, Grafana, Loki) · Alerting · Backup and restore.

## Level 4 — Advanced DevOps (Months 7–12)

GitOps with Argo CD · Advanced CI/CD · Deployment strategies (blue/green, canary) ·
Security: DevSecOps, Trivy, least privilege, secrets management, supply-chain · High
availability, scaling, resilience · Production projects · Incident response ·
Troubleshooting at scale.

## Level 5 — Expert DevOps and Platform Engineering (Month 12+)

Platform engineering, internal developer platforms, golden paths · Advanced GitOps
(App of Apps, ApplicationSets, multi-cluster, drift detection) · Advanced observability
and SRE (OpenTelemetry, tracing, SLIs/SLOs/SLAs, error budgets, chaos engineering) ·
Advanced infrastructure (multi-account, service mesh, zero trust, Policy as Code,
FinOps) · Advanced engineering practices and architecture trade-offs.

## Weekly structure (adjust freely)

| Day | Activity |
|---|---|
| 1 | Learn the first core topic |
| 2 | Continue with the next topic |
| 3 | Learn another related concept |
| 4 | Practice commands and practical implementation |
| 5 | Troubleshooting and scenario-based learning |
| 6 | Weekly practical project or lab |
| 7 | Revision, interview preparation, weekly test |

## Command system

`START` · `NEXT` · `NOTES` · `REVISION` · `WEEKLY TEST` · `MY PROGRESS` ·
`DOUBT: <question>` · `GIVE ME A HINT` · `SHOW SOLUTION` · `PROJECT` · `INTERVIEW` ·
`RESET DAY`
